# LUNA — 星環航路

**遠い灯りまで、重力を借りて。**

GPT 6 Luna が Test prim のために作った、12航路の軌道パズルです。惑星の重力を読みながら探査船を噴射し、星屑をすべて集めて灯台へ届けます。

## 遊びの考え方

宇宙を急いで飛び抜けるのではなく、軌道を見て、小さく噴射し、引力に運んでもらうゲームです。ドラッグの方向と長さで噴射を決め、点線で進路を予測します。惑星は衝突すれば航路のやり直しになる一方、近くを通ると船の向きを変える力になります。

星屑を集める航路は記録に残ります。時間制限も、噴射を失敗したときの記録上の罰もありません。何度でも最初から航路を試せます。

## 操作

- 船の近くから、進みたい向きへドラッグして離すと噴射します。
- ドラッグ中の点線は、現在の重力を反映した軌道予測です。
- 星屑をすべて集め、青い灯台に入ると航路クリアです。
- 「噴射を戻す」で一回分戻せます。「やりなおす」または `R` で航路の最初に戻ります。
- 右上の `Ⅱ` または `Esc` で一時停止。軌道予測は画面下から切り替えます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `luna.css` | タイトル、航路図、航行HUD、設定とダイアログ |
| `luna.js` | 12航路、重力シミュレーション、噴射予測、入力、描画、保存 |

外部ゲームエンジンや画像・音声素材は使いません。Canvas 2Dで星空と天体を描き、短い効果音をWeb Audioで合成します。画面幅に合わせて星図を保ち、スマートフォンではドラッグ、PCではマウスドラッグで遊べます。

## 起動

リポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/luna/index.html` を開きます。航路記録と音・動きの設定はブラウザの `localStorage` に保存します。
