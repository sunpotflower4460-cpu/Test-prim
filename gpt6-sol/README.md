# REPRISE — ひかりの再演

**昨日のあなたが、今日の扉を開く。**

GPT 6 sol の作品。ひとりの動きを「残光」として記録し、その残光と協力して劇場の幕を開ける、手番制の時間パズルです。3幕12場面。時間制限や失敗による損失はありません。

## 遊び方

1. 方向ボタン、盤面の隣のマス、または WASD / 矢印キーで足灯（丸いマーク）まで進む。
2. 足灯の上で「この動きを記録」。自分は最初の位置に戻り、残光が保存した動きを再演する。
3. 自分が一手動くたび残光も一手動く。動きの終わりには最後の位置に留まる。複数の足灯を灯すと幕が開く。第二幕からは偶数拍に開く拍子幕も登場する。
4. 出口の光まで進む。各場面の台本の欠片は任意。すべて拾うと、エピローグの言葉が変わる。

一手戻す、前の記録を直す、最初からやり直すことができます。中央の「待つ」または Space は、その場で一拍進めます。背後の残光を足灯まで進めたいときに使えます。全ての操作は拍単位で確定し、リアルタイムの反射神経は要りません。

## 作品の設計

人がいない劇場に残る「足音」を時間パズルのルールにしました。前の動きは実体のある残光として再演され、足灯を照らし続けます。一人のプレイヤーが二人、三人と協力しているように見える手触りを目指しています。最初の3場面で一つの残光、4場面目から二つの残光を導入します。

舞台・幕・足灯・残光・照明をCSSとSVGで描き、音はWeb Audioの発振器で合成します。外部ライブラリ、画像、音声、フォントは使いません。操作に合わせた音と、静かな和音の伴奏があります。音はいつでも切り替えられ、端末の「動きを減らす」設定にも対応します。

## 保存と独立性

クリア、欠片、開いた場面、現在の動きと残光をブラウザの `localStorage` に保存します。保存データの動きはルールエンジンで再演して検証し、壊れたものは読み飛ばします。保存が許可されない環境でも遊べます。

この作品は `gpt6-sol/` 内に独立して置き、共有タイトルのリンクとService Workerのオフライン資産一覧でのみ接続しています。既存のゲームの入力・音・画面には触れません。

## 起動と検証

リポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/gpt6-sol/index.html` を開きます。

```bash
node --check gpt6-sol/rules.js
node --check gpt6-sol/levels.js
node --check gpt6-sol/sound.js
node --check gpt6-sol/game.js
node --test tests/reprise.test.cjs
```

テストは全12場面で、足灯に残光を記録して出口へ行く解法と、台本の欠片を拾って出口へ行く解法を探索します。ルールと保存データの検証も確認します。
