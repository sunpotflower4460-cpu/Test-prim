# GPT6 CHAT — 2作品バグ監査

**実施:** 2026-10-13  
**対象:** `LUMINA — 星灯りの庭` / `KAZANE — 風の楽譜`  
**変更境界:** `game.js` と `gpt6-chat/` 以下のみ  
**検証形態:** ソース全体の確認、DOM/Canvas代替環境による挙動テスト、物理シミュレーション、差分監査

## 修正した箇所

| 作品 | 発見した問題 | 修正 |
| --- | --- | --- |
| LUMINA | 経験値上昇の祝福によって、ボスの章移行報酬に同じ倍率が2回掛かる | 基礎報酬を保管し、取得時に倍率を1回だけ適用 |
| LUMINA | 連続撃破ボーナスが経験値/レベルアップの共通処理を通らない | 次フレームで通常の経験値処理へ委譲 |
| LUMINA | キーボードのEnterで、2作品の選択画面を飛び越える | マウス操作と同じ作品棚へ遷移 |
| LUMINA | ボス報酬の画面表示が、祝福倍率を加味した実取得量と一致しない | 取得実数を表示 |
| LUMINA | ダッシュの衝撃波でボスが倒れてシーン遷移した後にも敵ループが続く | シーンの変更時点でループを終了 |
| LUMINA | 作品棚への帰還時に、進行記録が残らない経路がある | 帰還前に記録を確定 |
| KAZANE | 保存値に小数などの不正データが混入するとステージ参照に失敗する可能性 | 保存値を整数化して範囲制限 |
| KAZANE | ヒントの矢印がリスタートや次のステージに持ち越される | ステージ初期化時に表示状態をリセット |
| KAZANE | キーを押したまま「もどす」と、復元直後に移動が再開する | 取り消し時に入力状態を開放 |
| KAZANE | 動く障害物と種の座標が完全一致すると押し出し法線がゼロになる | 安全な脱出方向を用意 |
| KAZANE | 一部旧ブラウザでCanvasの`roundRect`が未実装 | 通常のパスでの描画フォールバックを追加 |
| KAZANE | 描画面外でタッチを離した際に風操作が残る場合がある | ウィンドウ側でも終了イベントを捕捉 |
| KAZANE | メニュー表示中もCanvasを60fpsで描画し続ける | メニュー中は描画を間引いて省電力化 |

## 検証結果

- `node gpt6-chat/audit-smoke.js`: **12 / 12 PASS**（GitHubから取得した最終ソースを使用した同じ監査関数で確認）
- LUMINA: 序盤の敵出現、経験値、レベルアップ、連続撃破の加算、1.4倍の祝福とボス報酬、弾の軌道と当たり判定、2作品への遷移を確認
- KAZANE: タップとドラッグ、取り消し、保存データ防御、ヒント、レベル解放、12番目の庭のエンディングを確認
- KAZANE: **実際の物理更新処理と方向入力を使ったルート追従シミュレーションで12/12ステージ開花**。岩・渦・動く障害物も含む
- 新規ライブラリ/API/ビルド環境の導入は不要

## 現時点での注意点

- テスト環境はDOM/Canvasを模したもので、**iPhone/Android実機の見た目・操作遅延・音の鳴り方・電力消費の実測ではない**。
- 既存のルートのService Worker (`sw.js`) はこの監査では変更していない。新作KAZANEを初回から完全オフラインで使えるようにする変更は未実施。キャッシュがない状態でのオフライン動作は保証しない。
- 自動プレイでの開花検証は最適な操作で遊んだ場合の可到達性確認であり、実際のユーザーの体感難易度は別途調整可能。

## 変更の独立性

既存の他AIのゲームフォルダには一切変更しない。ルートの他ゲームの入口も変更しない。
必要な修正はGPT6 CHATの元作品ファイル `game.js` と、専用作品フォルダ `gpt6-chat/` のみで完結させる。
