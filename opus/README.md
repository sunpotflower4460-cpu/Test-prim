# MIZUHO — 瑞穂　制作ノート（Opus 5.5）

**山の斜面に、水の段を。**

耕されなくなった山あいの村で、崩れた畦を盛り、斜面を均して棚田をひらき、湧き水を一枚ずつの田に巡らせて稲を育てる、水と土の箱庭です。八つの谷を、それぞれ一年かけて耕します。

## はじめての方へ

最初の谷に入る前に、祖母の手紙と、図つきの五ページの説明（この谷でやること・苗が植わる水・三つの道具・一年の流れ・操作）が出ます。説明はタイトルの「あそびかた」、ひと休み（Ⅱ）、プレイ中の「?」からいつでも開けます。

第一・第二の谷は手順つきのチュートリアルです。画面上部に「いまやること」が手順の番号つきで出続け、押すべきボタンが光り、できたら次の手順へ進みます（第一の谷：畦を盛る → 水を待つ → 田植え。第二の谷：均して段をつくる → 畦を盛る → 目標まで広げる → 田植え）。

各谷のはじめには「目標（秋に何俵）」「守る（家を浸さない）」「★の条件」をカードで示し、プレイ中も画面上部に「見込み / 目標」を出しています。

## あそび

| 道具 | はたらき |
| --- | --- |
| 盛る | 籠の土を盛る。ひとなでで、まわりで一番高い地面より「畦ひとつ分」だけ高くなる。崩れた畦をふさぐ、水をせき止める |
| 掘る | 土を掘って籠に入れる。ひとなでで掘れるのは、まわりより少し深いところまで。水路をつける、水を逃がす、水口を欠く |
| 均す | なぞり始めた高さに、まわりの土を揃える。高い側を削った土で低い側を埋めるので、斜面に平らな段ができる |
| 眺める | 指でなぞると景色が動く。＋－で寄る・引く、⟲⟳でまわる |

- **土は増えも減りもしない。** 掘った土は籠に入り、盛ると籠から減る。籠が空なら盛れず、満杯なら掘れない。
- **苗は、平らで、浅く、静かな水に植わる。** 深すぎても、流れていても、斜面でも植わらない。植えられる場所は春のあいだ淡く光る。
- **田植えまで時間は流れない。** 水は流れ続けるので、水の行き先を見ながらゆっくり整えられる。「田植え」を押すと一年（初夏・梅雨・盛夏・秋）が始まる。
- 梅雨の雨は低いところへ集まり、谷底の家を浸す。夏の日照りは泉を細らせ、田を乾かす。秋に実った稲を刈り取ったぶんが収穫になる（8区画で1俵）。
- 目標の俵に届き、どの家も浸からなければ、その谷はひらける。★は収穫の多さ。

### 八つの谷

| 谷 | 主題 |
| --- | --- |
| 一 一枚目 | 崩れた畦をひとつ盛る（「盛る」） |
| 二 段 | 斜面を均して段をつくり、縁に畦を盛る（「均す」） |
| 三 棚田 | 上の田からあふれた水で、下の田を満たす。畦の一か所を欠いて水口をつくる |
| 四 梅雨 | 長雨の水が谷底の三軒に集まる。尾根へ排水路を掘っておく |
| 五 石垣 | 岩がちの斜面には土がない。扇状地を掘って土を運び、盛り上げて段を築く |
| 六 尾根越え | 西の谷の泉を、尾根の鞍部を掘り抜いて東の斜面へ引く |
| 七 日照り | 崩れたため池の堤を直して春の水を貯え、夏に少しずつ落とす |
| 八 千枚田 | 二つの泉、村、梅雨と日照り。海までの斜面いっぱいに棚田を重ねる |

途中で手を止めた谷は、谷ごとにブラウザ内へ保存され、「谷の暦」から「つづきから」再開できます。

谷をひらくと、村の人から手紙が届きます。八つの谷すべてをひらくと、タイトルの谷は収穫の夜になります。

## しくみ

- `sim.js` — 地面（岩盤＋土）と水の高さ場。水は **virtual pipes 法**（隣り合うセルの水位差で流量が育ち、出せる水の量で頭打ちになる浅水モデル）で毎秒30回動きます。土は傾きが急すぎると崩れ（安息角）、濡れると崩れやすくなります。稲は「水深・平らさ・流れの静かさ」で植わり、水があるあいだ育ち、干上がるか水に沈むかが続くと枯れます。DOMに依存しない決定的なコードで、ゲームとテストが同じものを動かします。
- `levels.js` — 八つの谷とタイトルの谷。地形はセルごとの関数（決定的なノイズ＋手で置いた沢・堤・尾根・扇状地・浜）です。
- `script.js` / `solutions.js` — 道具を「手の速さ」で動かす再生器と、各谷の解き方。`tests/mizuho.test.cjs` が実際の道具・実際の水で一年を通して再生し、目標に届くこと、家が浸からないことを確かめます。逆に「何もしないと届かない」「梅雨の谷は排水路なしでは三軒とも浸かる」「日照りの谷はため池なしでは届かない」「尾根を掘らなければ届かない」ことも確かめます。土が増減しないこと、水が流れの中で保存されること、ひとなでの畦の高さ、戻すの復元もテストしています。
- `render.js` — WebGL2。シミュレーションの配列を毎フレーム浮動小数テクスチャとして送り、地形・水面・稲を頂点シェーダで組み立てます。水面は空と雲を映し、流れの速さで白く泡立ち、雨の輪が立ちます。稲は一株ずつの葉（インスタンス描画）と、遠目の「植わった田の色」の二層。影と環境遮蔽は高さ場からCPUで焼いています。谷は雲海に浮かぶ箱庭で、側面には土と岩の地層が見えます。
- `audio.js` — すべてWeb Audioの合成。流れる水、雨、季節の生き物（春のウグイス、田のアマガエル、夏のヒグラシ、秋のスズムシ）と、五音音階の琴のような音。カエルの声は、植わった田が広がるほど厚くなります。
- `game.js` — 画面、入力（指・マウス・二本指）、カメラ、季節の光、雨・花びら・蛍・白鷺・赤とんぼ・稲刈りの演出、保存。収穫の記録は一年が終わった瞬間に保存し、途中の谷は15秒ごとと、ページを離れるときに保存します。描画が重い端末では解像度を自動で下げ、軽くなれば戻します。

外部ライブラリ、画像、音声ファイルは使っていません（題字のフォントのみ Google Fonts、読み込めなくても表示できます）。

## 検証

```bash
node --test tests/mizuho.test.cjs          # 八つの谷の解法と、物理・道具の不変条件
node tools/mizuho-view.cjs tanada 0 out.png --script   # 解法を再生して上から見た図を書き出す
```

ブラウザ確認は `tests/browser-smoke.cjs` に、共有タイトルの九つ目の入口から第一の谷へ入り、実際のドラッグで畦を盛り、水が張るのを待って田植えをし、収穫して第二の谷がひらくまでを、スマホ・小型スマホ・横向き・PCの四サイズで追加しています。

WebGL2 が使えない環境では、その旨を表示して Test prim へ戻れるようにしています。音と描画は、 Safari と Firefox 、スマートフォン実機では未検証です。
