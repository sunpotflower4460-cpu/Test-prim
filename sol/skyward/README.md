# SKYWARD — 蒼穹の帰路

GPT 6.1 sol の第二作（GPT 6.1 sol 2）。空を守り、帰ってくる三人称3D戦闘機ゲーム。

[作品一覧](../works.html)から AFTERTIDE と選べます。[SKYWARDを開く](index.html)。ビルド不要で、リポジトリのルートから HTTP サーバーを起動します。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/sol/skyward/` にアクセス。WebGL 2に対応したブラウザで遊べます。PC・タッチ操作に対応し、小さい画面では横向きをおすすめします。作品と必要なライブラリはすべてこのリポジトリにあり、共有 Service Worker のインストール後はオフラインでも開けます。

## 空を飛び、空を守る

| 任務 | 目的 |
| --- | --- |
| 01 翼を知る | 8つの航法リングを順に通過し、帰投。旋回とエネルギー管理の訓練 |
| 02 白い航跡 | 無人標的3機を機関砲で撃破し、帰投。見越し射撃の訓練 |
| 03 海峡の影 | 基地へ向かう侵入機3機を迎撃し、帰投 |
| 04 灯を守る | 補給船団を襲う戦闘機3機を撃破し、船団を守って帰投 |
| 05 蒼穹の帰路 | 二波・6機の戦闘機を退け、基地へ帰る最終任務 |
| FREE 空の余白 | 最初から選べる自由飛行。群島を巡り、操縦・着陸の練習 |

任務を達成すると次が解放されます。任務中はリロードせず、ポーズからやり直せます。記録はブラウザに保存され、5秒ごと・停止時・ページを離れる時に途中の飛行も保存します。敵、弾薬、飛行中のミサイル、着陸の制動も再開できます。

## 操縦

| 操作 | PC | タッチ |
| --- | --- | --- |
| 機首上げ / 下げ | W / S、↑ / ↓ | スティックを上 / 下 |
| バンク | A / D、← / → | スティックを左 / 右 |
| ラダー | Q / E | バンクと目標ボタンで操縦 |
| 推力 | R / F | THR スライダー |
| アフターバーナー | Shift 長押し | AB 長押し |
| 機関砲 | Space / J 長押し | GUN 長押し |
| ミサイル | X | MISSILE |
| 目標を切り替える | Tab / T | 目標 |
| フレア | C | フレア |
| 降着装置 | G | 脚 |
| 水平に戻す | L 長押し | 水平 長押し |
| 追尾 / 広角 / 機首視点 | V | 視点 |
| 一時停止 | P / Esc | Ⅱ |

**翼を傾け、必要なぶんだけ引く**と旋回します。強く引き続けると抗力が増え、速度を失って失速します。推力を上げ、引きを緩めて回復してください。バンクの自動復帰、上下反転、操縦感度、音、描画品質を設定できます。飛行画面の FPS・画質ボタンからも設定でき、設定中は飛行が止まります。

キーボードで Shift+Tab を押すと操作欄にフォーカスを移せます。ボタンの Space / Enter は標準操作を保持し、戦闘操作が二重に発生しません。ウィンドウを離れると自動停止し、入力を解放します。

## 射撃と防御

- 機関砲は実際に弾を飛ばし、線分の交差で命中を判定します。黄色い見越し点は目標速度と弾速から計算します。射程はおよそ1.8km。加熱中のゲージが満杯になると、一度冷却します。
- ミサイルは距離250m〜6.2km・正面24°以内で1.5秒捕捉すると発射できます。旋回率・寿命があり、確実な命中ではありません。追尾する白い航跡も描画します。
- 戦闘機は追跡・射撃・ミサイル・離脱・フレアを使います。再捕捉して追い、残弾を管理してください。
- 敵ミサイルが2.6km以内に入ってからフレアを使うと追尾を外せます。警報とレーダーの赤い点を見て回避しましょう。
- 船団防衛では、遠くへ離れたプレイヤーより船団を優先する敵もいます。防衛対象の残量は任務欄に表示します。

## 帰投と着陸

任務達成後は金の帰投ビーコンが現れます。脚を上げた状態で、基地から1.15km以内・高度100〜1,000m・速度972 km/h未満を通れば帰投です。

**脚を下ろすと上空通過で終了せず、着陸を狙えます。** 滑走路の北から南（方位180°）へ、速度162〜414 km/h、ほぼ水平な翼と緩い降下で接地します。脚が出ていない、速すぎる、傾きすぎる、滑走路を外れる場合は失敗します。安全な接地後は滑走・制動し、停止してから結果を表示します。

機体60%以上を残して着陸するとS。上空通過の帰投は機体65%以上でA、それ未満はB。より良い評価、同評価なら短い時間を記録します。最終任務には専用の結末があります。

## 制作と飛行モデル

独自の機体、群島、滑走路、船団、雲、海、空、計器、音を制作しました。描画は同梱した Three.js 0.160.1（MIT）を使用し、CDNや外部画像・音声・フォントへの実行時アクセスはありません。

飛行処理は描画から分離し、SI単位・120Hzの固定刻みで動かします。動圧 `q = ρV²/2` と `L = qSCL` を用い、高度による大気密度、迎角と失速、誘導抗力、遷音速域の抗力増加、脚の抗力、推力、重力、燃料を扱います。バンクと荷重から航向・飛行経路角を更新し、迎角を足した機首方向から武器を発射します。

これは遊びやすさを調整した3自由度の飛行モデルです。機体の完全な6自由度剛体運動、実機の空力係数、航空電子機器、実在する兵器の性能は再現していません。設定値と敵AIはこのゲーム用に設計しています。

参考： [NASA Glenn — Lift Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/lift-equation/)、[NASA — Inclination Effects on Lift](https://www.grc.nasa.gov/WWW/k-12/VirtualAero/BottleRocket/airplane/incline.html)、[Three.js — WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)。ライセンスは [THREE-LICENSE.txt](vendor/THREE-LICENSE.txt)。

## 検証

```sh
node --test tests/skyward*.test.cjs
node --test tests/*.test.cjs
```

- 全5任務を通常の操縦入力と規定の武器で通し、撃破・防衛・帰投・最終結果を確認。検証用の操縦ロジックは `tests/helpers/skyward-pilot.cjs` に置き、ゲームには組み込んでいません。
- 巡航、旋回時のエネルギー低下、失速、推力、脚、燃料切れ、水平復帰、見越し射撃、捕捉条件、フレア、機関砲の加熱、増援の目標選択を検証。
- 航法リングの平面通過、進入・接地・滑走・制動、着陸途中の再開、失敗と終了後の停止を検証。
- 画面側のキー・スティック・停止・説明・記録・任務解放・破損した保存データを検証。
- Codex 内ブラウザで3D描画、実際のキー射撃、ドラッグ操縦、最初のリング通過、停止、説明、設定、視点、再読込での途中再開を確認。320×568、390×844、740×375、1280×800で表示と操作欄を確認。
- 共有 Service Worker のローカルテストで全アセットのプリキャッシュと、オフラインのディレクトリ入口を確認。

全任務の通し確認はシミュレーションのテストで行っています。Safari / Firefox、スマホ実機のGPU・同時マルチタッチ・音の聞こえ方、ブラウザを完全にオフラインにした実操作は未検証です。CIのブラウザースモークにも新作の開始・射撃・設定・途中再開・4画面サイズを追加していますが、そのスクリプト自体はローカルでは実行せず、実画面は Codex 内ブラウザで確認しました。
