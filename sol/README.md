# AFTERTIDE — 潮の郵便屋

**海の向こうに、待っている人がいる。**

GPT 6.1 sol がTest primのために制作した、18航路の海のパズル。コンセプト、盤面、物語、描画、音楽、実装を一つの小さな世界として設計しました。

## 作品の考え方

急いで反応するゲームではなく、海を読んで自分の航路を見つけるゲームです。「一手ごとに潮が変わる」だけのルールを土台に、待つ、浅瀬、潮流、門が違う意味を持ちます。間違えた手も、試した寄り道も、いつでも取り戻せます。

貝殻と最短記録は、配達のあとにもう一度海を見る理由です。ヒントや巻き戻しに罰はありません。手紙はクリアの報酬であり、離れた島々に人が住んでいることを伝える、小さな物語です。

## 海のルール

- 表示中の潮で隣のマスに進み、移動のあとで潮が入れ替わります。
- 満ち潮だけ浅瀬に入れます。潮が引いても舟は壊れず、錨で次の満ち潮を待てます。
- 満ち潮で矢印に入ると、連続する流れを一手で渡ります。流れの先が岩、または循環なら、その手は進めません。失敗した入力で手数や荷物は変わりません。
- 満ち潮で輪に入ると、もう一つの輪へ。到着した輪から再び転送されることはありません。
- 錨はその場で一手。流されず、潮だけを変えます。
- 手紙をすべて集めて灯台に入ると、その航路は終了します。貝殻を集めるときは、先に拾っておきましょう。
- 銅は配達、銀は貝殻も全部、金は貝殻全部を最短手数で配達。最短値は同じルールによる幅優先探索で求めます。

## 起動と操作

リポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/sol/index.html` を開きます。インストールやビルドは不要です。

WASD / 矢印キーで移動、Space で錨、Z / Backspace で一手戻す、H でヒント、P / Esc で一時停止。舟の隣をタップしても進めます。方向ボタンは斜めの海図と同じ向きです。Space はフォーカスされたボタンの操作を優先します。

音楽、効果音、海の動きを個別に設定できます。端末の「視差効果を減らす」設定にも対応。ダイアログの間は盤面の操作を止め、Tab キーのフォーカスをダイアログ内に保ちます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `tide.css` | タイトル、海図、日誌、レスポンシブ操作、手紙と設定 |
| `sim.js` | 副作用のないルール、最短探索、評価、保存データの検証 |
| `levels.js` | 18の手作り盤面、学習の順序、18通の手紙 |
| `sea.js` | 手続き描画の海・島・灯台・舟、航路の予告、移動と水面の演出 |
| `audio.js` | 三つの海の合成音楽、操作と配達の効果音 |
| `game.js` | 入力、画面遷移、保存・再開、巻き戻し、ヒント |

他作品とはページを分離し、入力、描画ループ、音声の状態を共有しません。共有タイトルのリンクとService Workerだけで接続します。描画は最大30fps、端末ピクセル比は最大2。動きを減らした場合は、静止時の再描画頻度をさらに抑えます。

保存キーは `aftertide-sol-v1`。航海の保存は移動履歴を再実行して検証し、保存ファイルの座標をそのまま信用しません。ブラウザの保存が使えない場合もプレイでき、配達結果に保存できなかった旨を表示します。共有Service Workerがこの作品の全ファイルもキャッシュします。初回の取得はネット接続が必要です。

## 検証

```bash
node --test tests/sol.test.cjs
node --check sol/sim.js
node --check sol/levels.js
node --check sol/game.js
node --check sol/sea.js
node --check sol/audio.js
```

11のルール検証で、全18航路の通常・金クリア、最短値、浅瀬、連続潮流、潮流の衝突と循環、門の片道転送、途中からのヒント、巻き戻し、壊れた保存データを確認します。

共有の `tests/browser-smoke.cjs` には、小型スマホ・スマホ・PCでの入口と操作、ヒント、再読み込みからの航海再開、保存された巻き戻し、PCでの全18航路の完走と54の記録を追加しています。GitHub ActionsのBrowser Experience Checksで実行されます。

制作時にはブラウザでも18航路を操作してすべて金で完走し、エンディング、海図、保存・再開、ヒント、巻き戻し、320×568 / 390×844 / 1280×800 / 横向きの画面を確認しています。

外部画像、外部音声、外部フォント、外部ライブラリは使用していません。
