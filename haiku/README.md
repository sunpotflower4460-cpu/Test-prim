# Haiku 5.5 — 制作ノート

Haiku 5.5 は、三つの作品を収める入口です。タイトル画面の一番下にある **Haiku 5.5** から、`haiku/index.html` の作品一覧に入ります。

| 作品 | 場所 | 形式 | 核になる仕組み |
| --- | --- | --- | --- |
| 鳴き井戸 — NAKI-IDO | `haiku/horror/` | 一人称・和風ホラーFPS（Three.js） | 見られていない間だけ近づく「だるまさんがころんだ」の掟、二連銃、電池式の懐中電灯、二つの結末 |
| おばちゃんの台所 | `haiku/kitchen/` | 三人称の3D料理ゲーム（Three.js） | 四つの料理（お味噌汁・卵焼き・肉じゃが・おにぎり）、失敗のない進行、おばちゃんにまかせる |
| 句ゆき | `haiku/ku/` | 墨絵の2D旅・俳句づくり（Canvas 2D） | 五・七・五の音数（自動で数える）、季語と切れ字の判定、八つの宿をめぐる句集 |

## 共通の作り

- **外部への依存はない**。CDN・外部フォント・画像・音声ファイルは使わず、三次元の描画に使うThree.js r160だけを `haiku/vendor/` に同梱しています（sol/skyward と同じ版）。音はすべて Web Audio で合成し、テクスチャは canvas で手続き生成しています。
- **判定などのルールは、描画と分けてある**。鳴き井戸は `sim.js`、台所は `sim.js` と `recipes.js`、句ゆきは `sim.js` と `words.js` に入り、node のテストで直接調べられます。ルールを描画に混ぜていないので、描画を変えても判定は変わりません。
- **保存は、ブラウザ内の一人ひとりの便利機能だけ**。localStorage を try/catch で囲み、保存が読めなくても遊べるようにしてあります。
- **スマートフォンに対応**。縦・小型・横の三つの大きさで、横スクロールや重なりがないことを確かめています。

## 検証

```bash
# 判定・状態遷移・保存のテスト（node 22 以降）
node --test tests/haiku-horror.test.cjs tests/haiku-kitchen.test.cjs tests/haiku-ku.test.cjs

# ブラウザでの操作の確認（サーバーを立てた上で）
python3 -m http.server 8000 --bind 127.0.0.1 &
BASE=http://127.0.0.1:8000 node tests/haiku-horror-browser.cjs
BASE=http://127.0.0.1:8000 node tests/haiku-kitchen-browser.cjs
BASE=http://127.0.0.1:8000 node tests/haiku-ku-browser.cjs
```

CI では、**Quality Checks** が構文とテストを、**Browser Experience Checks** が上の三つのブラウザ検証を実行します。

## 検証できた範囲と、できなかった範囲

**確かめた**
- 三作品の node テスト（鳴き井戸36件、おばちゃんの台所16件、句ゆき19件）がすべて通ること
- 三作品のブラウザ検証（タイトル、操作、拾う・装填・撃つ、日記、一時停止、携帯の画面、横はみ出しのなさ）
- 鳴き井戸の両方の結末、おばちゃんの台所の配膳と家族の反応、句ゆきの句の判定と句集

**確かめていない**
- **音**。合成はしてあるが、実際の音を聞いて調整してはいません。
- **実機のタッチ操作**。タッチはエミュレーションで確かめただけです。
- **フレームレート**。この環境の描画は software で、1〜5 fps しか出ません。中位のスマートフォンで60fpsを保てるかは測っていません。
- **日本語フォント**。この環境には Hiragino / Yu Mincho がないため、スクリーンショットは代替フォントで撮っています。

## 作品ごとの残りの課題

- **鳴き井戸**：雨は画面に重ねる2D表現です。樋（とい）の音は未実装です。戸口の幅は 1 m で、設計の 0.8 m より広くしています。
- **おばちゃんの台所**：キーボードでのドラッグ操作は、後から追加したため、ブラウザ検証では触れていません。切ったり混ぜたりしている最中の画面も、スクリーンショットでは確認していません。
- **句ゆき**：最後の宿（峠）は、どの季節の句でも受け付けます。句の評価は、季語と切れ字の有無にもとづく規則です。句の良し悪しを読んで判断するものではありません。
